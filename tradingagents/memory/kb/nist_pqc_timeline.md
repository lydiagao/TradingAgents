# NIST Post-Quantum Cryptography (PQC) Timeline

## Finalized Standards (2024)
- **FIPS 203**: ML-KEM (CRYSTALS-Kyber) — key encapsulation
- **FIPS 204**: ML-DSA (CRYSTALS-Dilithium) — digital signatures
- **FIPS 205**: SLH-DSA (SPHINCS+) — hash-based signatures (stateless)

## In Progress
- **FIPS 206**: FN-DSA (FALCON) — lattice-based signatures (expected 2025)
- **Additional signatures**: HQC selected for standardization (Round 4)

## Mandated Migration Timeline
- **2025-2030**: US federal agencies must inventory cryptographic systems
- **2030-2033**: Begin migration to PQC for sensitive systems
- **2035**: Full PQC deployment mandate (per NSM-10 / OMB M-23-02)

- **Tailwind**: Companies with PQC solutions see demand pull (e.g., Quantinuum's cybersecurity division)
