# Quantum Vendor Roadmaps (as of Q1 2026)

## IBM
- **Condor** (1121 qubits, 2023): Largest superconducting processor
- **Heron** (133 qubits, 2024): Error-mitigated, higher fidelity
- **Roadmap**: 100K+ qubits by 2033 via modular architecture
- **Key metric**: Quantum Volume doubled annually through 2024

## Google
- **Willow** (105 qubits, 2024): First below-threshold error correction demonstration
- **Significance**: Proved that adding more qubits REDUCES errors (threshold crossed)
- **Roadmap**: Targeting useful quantum advantage by 2029

## IonQ (IONQ)
- **Forte Enterprise** (36 algorithmic qubits, 2024)
- **Tempo** (next-gen, 2025): Targeting 64+ algorithmic qubits
- **Key differentiator**: #AQ (algorithmic qubits) metric; highest all-to-all connectivity
- **Revenue path**: Hybrid cloud via AWS Braket, Azure Quantum, Google Cloud

## Rigetti (RGTI)
- **Ankaa-3** (84 qubits, 2025): Targeting 99.5% two-qubit gate fidelity
- **Strategy**: Vertical integration — designs and fabs own chips
- **Challenge**: Competing against IBM's fab scale advantage

## D-Wave (QBTS)
- **Advantage2** (7000+ qubits, annealing, 2024)
- **Gate-mode**: Added gate-based capabilities alongside annealing
- **Differentiator**: Only company with commercial quantum annealing at scale
- **Revenue**: Highest among pure-plays (~$15M ARR)

## Quantinuum (private, HON subsidiary)
- **H2** (56 qubits): Highest measured Quantum Volume (2^20)
- **Strategy**: Focus on quality over quantity; enterprise customers
- **Revenue**: $100M+ projected 2025; considering IPO

## PsiQuantum (private)
- **Approach**: Photonic, manufacturing via GlobalFoundries
- **Claim**: Million-qubit architecture possible via existing semiconductor fab
- **Risk**: No independently verified prototype; mostly PowerPoint so far
